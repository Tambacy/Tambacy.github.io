# 乒乓一站式平台 — 添加用户注册、登录、评论功能

## Why
当前网站是一个纯静态单页面，所有数据存储在浏览器 localStorage 中，不同用户之间无法互动。升级为支持注册、登录、评论的 Web 应用后，网友们可以创建自己的账号、保存诊断结果、发表评论互动，让平台从个人工具变成社区平台。

## What Changes
- 新增后端服务器（Node.js + Express + SQLite），处理用户认证和评论数据
- 新增用户注册功能（邮箱 + 密码）
- 新增用户登录功能（JWT 令牌机制）
- 新增评论系统（可对诊断结果/训练内容发表评论，可查看他人评论）
- 前端使用 web-artifacts-builder 技能重建为 React + TypeScript + Tailwind CSS + shadcn/ui 架构
- 保留所有现有的诊断测试、进阶指南、训练教程、AI 建议功能不变

## Impact
- Affected specs: 所有现有 Tab 页面（诊断测试、进阶指南、训练教程、AI建议）
- Affected code: 整个项目从单文件 HTML 拆分为前端 React 项目 + 后端 Express 项目
- 新增目录结构: `/frontend/` (React 前端), `/backend/` (Express 服务端)

## ADDED Requirements

### Requirement: 用户注册
系统 SHALL 提供用户注册功能，用户通过邮箱和密码创建账号。

#### Scenario: 成功注册
- **WHEN** 用户提供有效的邮箱（未注册过）和密码（至少6位）
- **THEN** 系统创建新用户账号，密码经 bcrypt 加密存储，自动登录并跳转到首页

#### Scenario: 邮箱已被注册
- **WHEN** 用户使用已注册的邮箱尝试注册
- **THEN** 系统提示"该邮箱已被注册，请直接登录"

#### Scenario: 输入不合法
- **WHEN** 用户提交空邮箱、无效邮箱格式、或密码不足6位
- **THEN** 系统在表单中显示对应的验证错误提示

### Requirement: 用户登录
系统 SHALL 提供用户登录功能。

#### Scenario: 成功登录
- **WHEN** 用户提供正确的邮箱和密码
- **THEN** 系统验证通过，返回 JWT 令牌，前端保存令牌并显示用户已登录状态（导航栏显示用户名）

#### Scenario: 密码错误
- **WHEN** 用户提供正确的邮箱但错误的密码
- **THEN** 系统提示"密码错误，请重试"

#### Scenario: 自动登录
- **WHEN** 用户之前登录过且 JWT 令牌未过期
- **THEN** 系统自动恢复登录状态，无需重新输入密码

### Requirement: 用户登出
系统 SHALL 提供登出功能。

#### Scenario: 用户主动登出
- **WHEN** 已登录用户点击"退出登录"
- **THEN** 前端清除 JWT 令牌，导航栏恢复为"登录/注册"按钮

### Requirement: 评论发表
系统 SHALL 允许已登录用户发表评论。

#### Scenario: 发表评论成功
- **WHEN** 已登录用户在评论区输入内容（不超过500字）并提交
- **THEN** 评论保存到数据库，页面实时显示新评论，包含用户名和时间

#### Scenario: 未登录用户尝试评论
- **WHEN** 未登录用户在评论区输入内容并提交
- **THEN** 系统提示"请先登录后再发表评论"，并将用户引导至登录页面

#### Scenario: 空评论
- **WHEN** 用户提交空内容
- **THEN** 系统提示"评论内容不能为空"

### Requirement: 评论展示
系统 SHALL 在平台首页或各内容区域展示用户评论列表。

#### Scenario: 查看评论列表
- **WHEN** 用户访问平台
- **THEN** 展示所有用户的评论列表，按时间倒序排列，每条评论显示发布者昵称、发布时间、内容

#### Scenario: 分页加载
- **WHEN** 评论数量超过20条
- **THEN** 系统分页加载，每页20条，显示"加载更多"按钮

### Requirement: 评论删除（自己的评论）
系统 SHALL 允许用户删除自己发表的评论。

#### Scenario: 删除自己的评论
- **WHEN** 已登录用户点击自己评论的删除按钮
- **THEN** 评论从数据库和页面中移除

#### Scenario: 尝试删除他人评论
- **WHEN** 用户尝试删除他人评论（如通过直接调用API）
- **THEN** 后端返回 403 禁止操作

### Requirement: 诊断结果持久化
系统 SHALL 将已登录用户的诊断测试结果保存到服务器。

#### Scenario: 保存诊断结果
- **WHEN** 已登录用户完成诊断测试
- **THEN** 诊断结果（球员类型、六维分数）自动保存到服务器，用户下次登录可查看历史记录

#### Scenario: 未登录用户做测试
- **WHEN** 未登录用户完成诊断测试
- **THEN** 诊断结果显示但仅保存在浏览器 localStorage 中，提示用户注册后可永久保存
